# Classififcation-Sport-Dataset-usingcnn

The Sports Image Classification project from Ain Shams University’s Faculty of Engineering (CSE485 Deep Learning) involves developing a Convolutional Neural Network (CNN) to classify images from the Kaggle Sports Image Classification dataset into various sports categories. The project is divided into two parts: first, preparing the dataset by downloading, describing, cleaning, and visualizing it, checking for missing values or duplicates, performing correlation analysis, splitting it into 80% training and 20% test sets, standardizing features, and encoding labels; second, designing and training a CNN model while experimenting with hyperparameters like batch size, number of layers, dropout rates, optimizers (e.g., SGD, Adam), L2 regularization, and learning rate schedules to optimize performance and prevent overfitting.
